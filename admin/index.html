Anmelden

Das Admin-Panel speichert Änderungen direkt in deinem GitHub-Repo Iamioo.github.io. Dafür brauchst du einmalig einen Token:

  1. Öffne github.com/settings/personal-access-tokens/new
  2. Name z. B. „Spiele-Admin“, Ablaufdatum nach Wunsch
  3. Repository access → „Only select repositories“ → Iamioo.github.io
  4. Permissions → Repository permissions → Contents → „Read and write“
  5. „Generate token“ klicken und den Token hier einfügen

Der Token bleibt nur in deinem Browser und wird ausschließlich an api.github.com geschickt.
